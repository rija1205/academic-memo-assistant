# Prototype ThesisFlow conservé

Ces trois fichiers sont une copie intacte du prototype visuel initial :

- `index.html`
- `app.js`
- `styles.css`

Ils servent de référence pour l'identité visuelle (palette navy/bleu, typographie, tableau de bord et disposition en trois colonnes). Ils ne sont pas montés par la page Next.js de l'étape 2 et ne doivent pas être confondus avec le backend de production.

La migration fonctionnelle sera réalisée progressivement lors des étapes suivantes, sans supprimer le prototype tant que la nouvelle interface n'est pas validée.
